<h1 align="center">
  Web Application For My Girlfriend
</h1>

Only me and my girlfriend will use this web app

## Theme

- Cat theme
- Focused on light mode
- Pastel colors
- Sans typography
- Sleek UI with a touch of cute

## Features

1. Login
    - So only me and my partner can use it.
2. Photobooth
    - Website takes a set of pictures. User chooses a frame design. The output gets generated.
3. Music (Mini Spotify)
    - Users can create playlists, search and play songs, or add them to playlists.
    - Adding songs can be done through search using a package like `yt-search`, or by manually adding a YouTube URL.
4. Gallery
    - Users can upload images, and they will all be displayed like a Gallery wall (like Pinterest).
    - Images have checkbox for download/delete.
    - Images should be lazy loaded for performance.
5. Virtual scrapbook
    - Canva-like environment where users can import assets and create virtual scrapbook pages using those assets.
    - Users can place their uploaded assets, or the images uploaded from the gallery.
6. Spin the wheel
    - UI design will carry this feature
7. Game inspired by Pou but for cats
    - Built with `Phaser`
    - Multiplayer game using WebSockets where we take care of a pet cat (Users have live cursor)
    - When this tab is not active, a mini window of the pet will appear at all times at the side of the screen that we can interact with (pet by clicking with cursor, or throw ball at it).
